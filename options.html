How to get a Gemini API key

CV Adapter uses your own key to Google Gemini. Creating it is free, and the free tier is enough for normal use.

  1. Open Google AI Studio → API keys and sign in with your Google account.
  2. Click Create API key. If no project is listed, choose Create project first.
  3. Copy the key — it starts with AIza. It is only shown in full when you create it, so save it right away.
  4. Paste it into the Gemini API key field below and click Save settings at the bottom.

The key is personal: it is stored only in this browser profile, never synced between profiles, and sent only to Google's API. You can revoke it at any time in AI Studio. See Privacy and data for what leaves your computer.

    Skills

    Off: only skills supported by the CV (fully or partially) can be selected. Skills without evidence cannot be added.
    On: skills without evidence in the CV can also be selected. They are clearly marked in the skill picker and you are responsible for reviewing and approving them. Nothing is added automatically.

    Privacy and data

    What leaves your computer: the ad text and the CV text are sent to Google Gemini for analysis and text proposals. The template and the copy are handled through the Google Docs and Drive APIs. The extension has no server of its own and sends nothing anywhere else.

    Gemini's free tier: Google's terms for the free tier mean that content may be used to improve their products. If you want to avoid that, a paid key at Google is the only option — the extension never uses paid models on its own.

    What is stored locally: the API key (only in this browser profile), settings, cached requirement analyses, the call counter and the history of created documents. Settings are synced between your Chrome profiles, but never the API key.

    Rules for CV adaptation

    • Only text between matching [TAG] and [/TAG] can be changed.
    • Text that already fits the ad is left unchanged.
    • The AI must not invent skills or experience.
    • All tags are removed in the created copy, even if the content is unchanged.
    • Only the sections between tags are edited.

    The history is stored locally in this Chrome profile. The Google Docs documents are stored in your Google Drive.
